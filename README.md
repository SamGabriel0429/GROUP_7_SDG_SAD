# ReliefTrack PH

## Community Disaster and Aid Management System

### SDG Goal
SDG 9 - Industry, Innovation and Infrastructure

### Project Description
This project aims to create a role-based disaster management system that improves relief operations in Barangay San Perfecto using a digital platform with audit logging and real-time request tracking.

The system uses a 3-tier architecture because it allows clear separation of presentation, logic, and data layers, making the system maintainable and scalable for barangay-level operations.
