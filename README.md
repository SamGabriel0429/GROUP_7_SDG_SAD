# GROUP_7_SDG_SAD

Project Title and SDG Goal
ReliefTrack PH: Community Disaster and Aid Management System

SDG 9 - Industry, Innovation and Infrastructure

The system addresses the problem of inefficient, paper-based disaster relief management in Barangay San Perfecto. Current manual processes cause delays in request approvals, lack of transparency in donation tracking, and poor coordination among barangay officials, volunteers, and donors. ReliefTrack PH provides a centralized, role-based digital platform that streamlines relief requests, task assignments, donation management, and audit logging.

Project Description
ReliefTrack PH is a role-based disaster management system designed for barangay San Perfecto. The system supports five primary actors: Resident, Donor, SK Kagawad, SK Chairman, and Barangay Chairman.

Architecture Justification:

The system follows a 3-Tier Architecture consisting of:

Presentation Tier: Responsive web interface using HTML5, CSS3, and JavaScript

Logic Tier: Client-side business logic with role-based access control

Data Tier: JavaScript arrays for prototype, with MySQL recommended for production

This architecture was chosen because:

It enables rapid prototyping and testing

It supports offline-capable forms for disaster scenarios

It provides clear separation of concerns

It aligns with SDG 9 by digitizing local government operations
